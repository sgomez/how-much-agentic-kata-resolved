# Games

The game people gather in behind a code: who is in it, who runs it, its settings, which round it is on and when it is over.

## Language

### People

**Player**: A person inside a game. Someone signed in to the app who has not joined any game is not a player. Nobody leaves a game: a player who closes the app is still a player until the game is finished. _Avoid_: Participant, user

**Host**: The player who runs the game. The host plays like everyone else and stays the host until the game is finished. _Avoid_: Owner, admin, creator

**Nickname**: The name other players see. Unique within a game, ignoring case and spaces at either end. _Avoid_: Username, alias, display name

### The game

**Game**: What players join with a code ("partida" on screen). Playing again is a new game with a new code. _Avoid_: Match, session, room

**Code**: What players type to join a game. Unique only while the game exists. _Avoid_: PIN, room code, join code

**Settings**: The choices that shape a game: its packs, the seconds each round lasts, the number of rounds (5 unless the host picks another) and whether impostor mode is on. The host chooses them when creating the game, and they never change afterwards. _Avoid_: Options, config, rules

**Impostor mode**: The setting that gives every round of a game one impostor. A game in impostor mode needs at least three players to start. _Avoid_: Impostor game, impostor variant

**Lobby**: The first phase of a game, before the host starts it. Players can only join a game while it is in the lobby, and the host can only start it with at least two players. It is a moment of the game, not a place. _Avoid_: Waiting room

**Playing**: The phase of a game between the start and finished. It begins once round 1 exists. _Avoid_: Started, in progress, in round

**Current round**: The number of the round a game is on. It only moves on once that round exists. A game in the lobby has none; a finished game keeps the last one it played. _Avoid_: Turn, active round

**Finished**: The last phase of a game: the host ended it after the last round, or moved on when the deck was exhausted. _Avoid_: Over, ended, closed
