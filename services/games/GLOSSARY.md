# Games

The game people gather in behind a code: who is in it, who runs it, its settings, which round it is on and when it is over.

## Language

### People

**Player**: A person inside a game. Someone signed in to the app who has not joined any game is not a player. _Avoid_: Participant, user

**Host**: The player who runs the game. The host plays like everyone else. _Avoid_: Owner, admin, creator

**Nickname**: The name other players see. Unique within a game, ignoring case and spaces at either end. _Avoid_: Username, alias, display name

### The game

**Game**: What players join with a code ("partida" on screen). Playing again is a new game with a new code. _Avoid_: Match, session, room

**Code**: What players type to join a game. Unique only while the game exists. _Avoid_: PIN, room code, join code

**Settings**: The choices that shape a game: its packs, the seconds each round lasts, the number of rounds (5 unless the host picks another) and whether impostor mode is on. The host chooses them when creating the game. _Avoid_: Options, config, rules

**Impostor mode**: The setting that gives every round of a game one impostor. _Avoid_: Impostor game, impostor variant

**Lobby**: The first phase of a game, before the host starts it. Players can only join a game while it is in the lobby. It is a moment of the game, not a place. _Avoid_: Waiting room

**Current round**: The number of the round a game is on. It only moves on once that round exists. _Avoid_: Turn, active round

**Finished**: The last phase of a game: the host ended it after the last round, or moved on when the deck was exhausted. _Avoid_: Over, ended, closed
